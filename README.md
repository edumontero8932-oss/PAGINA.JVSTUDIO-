# JV.STUDIO — Entrega corregida

Se ajustó el bloque del QR de WhatsApp para que el archivo PNG ocupe más espacio dentro del mismo cuadrado blanco, respetando el borde blanco exterior y sin tocarlo. El contenedor conserva su tamaño, mientras que el margen interno pasó de 16 px a 10 px.

## Archivos

Abre `index.html` en tu navegador. Conserva `style.css`, `script.js` y la carpeta `assets` junto al HTML.

Para servirlo localmente: `python -m http.server 3000`.
