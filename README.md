## Archivos

- `index.html` — página principal (con los textos corregidos).
- `style.css` — estilos (incluye el nuevo diseño de tarjetas de servicios).
- `script.js` — interacciones (menú, lightbox, año automático).
- `assets/` — imágenes del sitio:
  - `assets/projects/` — trabajos del portafolio.
  - `assets/social/` — iconos de Instagram, LinkedIn, Behance y TikTok.
  - `assets/tools/` — iconos de software (Photoshop, Illustrator, 3ds Max, etc.).
  - `assets/qr-code.png` — QR de WhatsApp.

## Cómo usarlo

Abre `index.html` en tu navegador. Conserva `style.css`, `script.js` y la
carpeta `assets` junto al HTML.

Para servirlo localmente: `python -m http.server 3000`.
